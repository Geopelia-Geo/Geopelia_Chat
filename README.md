# AI 聊天助手 (Android)

一个纯 Java 的 AI 聊天 App，对接 **OpenAI 兼容接口**，**默认 DeepSeek（API 地址 + deepseek-chat 模型、温度 1.0）**，
也支持 ChatGPT / 通义千问 / 智谱 / Moonshot / Ollama 本地模型。系统提示词已内置在 `assets/prompt.md`，不可在 App 内修改。

## 特性
- ✅ 最低支持 **Android 5.0（API 21）**，无原生库、纯 Java，**32 位 / 64 位设备都能跑**
- ✅ 可填写任意 OpenAI 兼容的 Base URL + API Key + 模型名
- ✅ **默认 DeepSeek**：接口地址 `https://api.deepseek.com/v1`、模型 `deepseek-chat`、温度 **1.0**
- ✅ **系统提示词内置**：读取 APK 内部 `assets/prompt.md`，用户不可修改（如需改提示词，修改该文件后重新打包）
- ✅ **LINE 风格界面**（原生布局照搬参考稿：白底顶栏带返回‹/对方头像/用户名/状态/☰菜单，灰绿气泡带时间与"已读"，底部 输入框+表情+发送↑，无 WebView 依赖）
- ✅ **绿色主题**（LINE 绿 #06C755，与界面统一）
- ✅ **返回键回主屏幕**：顶栏 ‹ 一键回到系统桌面（电话按钮已去掉）
- ✅ **头像**：AI 头像仍用你提供的内置图；自己的头像在设置页可自定义；连续同一个人发的多条消息**只显示一次头像**
- ✅ **微信式多行发送**：输入框内有多行文本时，按行拆成多条独立消息逐条发送，每条间隔随机 **0.3~0.7 秒**
- ✅ **自定义聊天背景图**：设置页可从相册选择图片作为背景，自动采样压缩，可一键恢复默认
- ✅ **聊天记录记忆**：自动持久化保存，重启 App 不丢失
- ✅ **上下文条数可调**：发送时附带最近 N 条历史给模型，默认 30 条，可在设置里改（0~200）
- ✅ **撤回 / 回溯 / 删除**：长按任意消息弹出菜单
  - 复制内容
  - 删除此条
  - 撤回此条及回复（仅用户消息，同时删掉对应的 AI 回答）
  - 回溯到此处（删除该消息之后的全部记录，从该位置继续对话）
- ✅ 清空聊天记录按钮已移到「设置」页
- ✅ 零第三方网络 SDK，仅用 Android 自带的 HttpURLConnection + org.json，体积小
- ✅ 已签名，可直接安装分发（release 版）

## 直接安装（不用编译）
- 正式版：`AiChat-v1.13.1-release.apk`（推荐，签名可长期升级安装）
- 调试版：`AiChat-v1.13.1-debug.apk`

把 APK 传到手机（Android 5.0+，32/64 位均可），允许“未知来源安装”后点击安装即可。

## 使用方法
1. 打开 App，点顶栏 **☰** 打开设置
2. 只需填写 **API Key**（默认已填好 DeepSeek 地址 `https://api.deepseek.com/v1`、模型 `deepseek-chat`、温度 1.0）
   - 也可改成其他：接口地址（ChatGPT 用 `https://api.openai.com/v1`，通义 `https://dashscope.aliyuncs.com/compatible-mode/v1`，智谱 `https://open.bigmodel.cn/api/paas/v4`，本地 Ollama `http://<电脑IP>:11434/v1`）、模型名、温度、最大 Token
   - **上下文条数**：默认 30，发送时附带最近 N 条聊天记录；设为 0 则不附带历史
3. （可选）在「外观」区：**选择我的头像**、**选择聊天背景图**、恢复默认
4. 保存后返回主界面即可对话
5. 顶栏 **‹** 返回键会直接回到手机主屏幕
6. **多行输入**：输入时按回车换行，点发送后自动拆成多条独立消息逐条发出（间隔 0.3~0.7 秒）；同一个人连续发的多条消息只显示一次头像
7. **表情**：输入框左侧的笑脸按钮是矢量图标，点开会弹出**黄脸 emoji 面板**，点击表情即插入到输入框
8. **长按任意消息**可复制、删除、撤回或回溯；**清空全部记录**在设置页底部。

## 用 Android Studio 打开工程
1. 安装 [Android Studio](https://developer.android.com/studio)（版本建议 2023+）
2. File → Open → 选择本目录 `AiChatApp`
3. 首次打开会自动用 Gradle Wrapper 下载依赖
4. 可直接 Run 到模拟器或真机；重新打包 APK：`Build → Build APK(s)`

命令行打包（需要 JDK 17 + Android SDK）：
```bash
./gradlew :app:assembleDebug    # 调试版
./gradlew :app:assembleRelease  # 正式版
```
